# 云大学习空间助手

这是《软件开发综合实践》期末大作业的本地仓库。项目围绕“校园公共信息与数据展示中心”主题，帮助学生查询学习空间、安排学习计划、查看统计趋势并浏览三维校园地标。

当前仓库先完成了基础结构、本地依赖和演示数据，后续功能提交会继续补充页面、交互、图表、三维场景与测试记录。

## 技术范围

- HTML5、CSS3、JavaScript
- Bootstrap 5.3.8、jQuery 3.7.1
- ECharts 5.6.0
- Three.js 0.128.0 + OrbitControls

所有第三方库均保存在 `libs/`，业务数据保存在 `data/`，不依赖 CDN。
